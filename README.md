# 思源智审

“交我创”智能体创新大赛初赛演示。原仓库的更新包保留在根目录，演示站点由 `dist/` 提供。

## 演示

1. 点击「载入演示材料」，核对模拟培养方案后点击「确认并启用」。两个 PDF 也可从页脚下载，分别手动导入。
2. 运行「推免学业审查」。模拟案例的截止学期为 2025–2026 学年第一学期末。模拟学生林澄在截止前完成应修课程，周禾仍有应修课未通过。截止后通过的同一门课不会补计。
3. 切换「毕业预审」后再次运行。林澄的毕业设计在修，需复核。周禾的毕业设计和专业选修均已通过，达到模拟方案的要求。

## 自带材料

- 在 i.sjtu 的培养计划查询中按年级、学院、专业打开所需方案，从预览保存 PDF 再导入。站点支持原教务格式的文字型 PDF，预览中可核对课程、学分、说明及对应页码。
- 确认后的培养规则保存在当前浏览器中。修业记录和结果仅保留在当前页面的内存，刷新后需要重新选择修业文件。校内账号和成绩单都不经过部署服务器。
- 推免演示只核对截止学期内应通过的必修和有明确建议学期的培养类型指定课程。选修学分、独立计次、排名、处分及外语等不在此口径内。毕业预审按当前培养规则中已配置的要求计算，未落实为规则的原文需人工核对。
- 模拟材料全部为虚构数据。结果仅供人工复核，正式资格由学校或学院认定。

## 本地运行与部署

用能以 JavaScript MIME 类型提供 `.mjs` 的静态服务器托管 `dist/`。安装 Node.js 后，可在仓库根目录执行 `npx --yes http-server dist -p 8000 -c-1`，访问 `http://localhost:8000`。Vercel 项目从仓库根目录导入，使用 `vercel.json` 中的静态输出目录。运行和部署均无需配置数据库、模型 API 或环境变量。

本站复用了原仓库中的 PDF 解析和审查引擎，以及更新包内提供的 PDF.js 和 JSZip。PDF.js 与其字库的许可随资源保留。
